# -4-Bit-Full-Custom-ALU-VLSI
4-bit full-custom ALU designed and verified in Cadence Virtuoso, from transistor-level schematic to layout, including DRC/LVS, PEX, pre/post-layout simulation, PVT, Monte Carlo, timing &amp; worst-case analysis, arithmetic/logic functions, flags, and PPA/PDP/EDP evaluation.
